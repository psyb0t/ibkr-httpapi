# ibkr-httpapi Go client

Typed Go client for [ibkr-httpapi](https://github.com/psyb0t/ibkr-httpapi), generated from `api/v1.yaml` by oapi-codegen.

```bash
go get github.com/psyb0t/ibkr-httpapi/pkg/clients/go@latest
```

Usage, authentication and a full example: https://psyb0t.github.io/ibkr-httpapi/clients/

`client.gen.go` is generated. Never edit it; change the spec and run `make generate-client-go` in the repository root.
